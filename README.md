# The Goa Games: Bingo

Two static pages for the Sales Cloud UX onsite in Goa, served by GitHub Pages.

- `index.html` is the **player card**. Everyone opens it on their phone and gets their own shuffled 4×4 card. Tap a square, add the name of someone who matches. One person can fill at most two squares. Complete a line and the page shouts BINGO.
- `host.html` is the **host screen** for the TV: game clock (15, 20 or 25 minutes), a Hall of Fame you fill from a name dropdown, and a QR code to the player card. Press H to hide the controls.

Everything is saved in each browser, so there is no server or database.
