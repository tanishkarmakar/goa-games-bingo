# The Goa Games: Bingo

Two static pages for the Sales Cloud UX onsite in Goa, served by GitHub Pages.

- `index.html` is the **player card**. Open it on any device, tap your name, and get your own shuffled 4×4 card. Tap a square, tap the name of someone who matches. One person can fill at most two squares. Squares one away from a line glow, and completing a line shouts BINGO.
- `host.html` is the **host screen** for the TV: game clock (15, 20 or 25 minutes) with sound cues, a Hall of Fame you fill with one tap per name, and a QR code to the player card. Press H to hide the controls.

Everything is saved in each browser, so there is no server or database.
