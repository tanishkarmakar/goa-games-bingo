# BINGO, BONGO, BANGO!

A dark-disco people-bingo for the Sales Cloud UX onsite in Goa. Two static pages on GitHub Pages.

- `index.html`: the **player card**. Tap your name, get a shuffled 4×4 card, tap a square, tap whoever matches. Max two squares per person. 1 line = BINGO. 2 lines = BONGO. Full card = BANGO.
- `host.html`: the **host controls**, on your laptop. Game clock with presets, custom time and live nudges. Hall of Fame for all three tiers, one tap per name. QR code to the player card.
- `display.html`: the **TV screen**. Open it from "Open TV view" on the host, drag it to the TV, click once for sound and full screen. It opens on a six-slide intro deck, which also shows on the host screen with presenter buttons (Back, Next, Open TV view, Skip to controls). Arrow keys, a clicker or clicks work on either screen, then goes live: the host screen, minus the controls. Pressing Start also skips straight to live. "Show intro deck" brings it back. It syncs through the browser, so both must run in the same browser on the same computer.

No server. Everything lives in each browser.
